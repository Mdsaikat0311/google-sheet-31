GitHub Pages লোডিং গাইড

GitHub Pages এ সাইট চালু করার জন্য GitHub রিপোজিটরির Settings-এ নিচের সেটিংসটি নির্বাচন করুন:

পদ্ধতি ১ (স্বয়ংক্রিয়):
GitHub Repo > Settings > Pages এ যান এবং Source এ "GitHub Actions" সিলেক্ট করুন।
পদ্ধতি ২ (ব্রাঞ্চ থেকে):
Source এ Deploy from a branch থাকলে Folder হিসেবে /docs সিলেক্ট করুন।
বিল্ড ভার্সন খুলুন (/docs)
